# 搜索页面

> https://api.coolapk.com/v6/search

*请求方式：GET*

认证方式：X-App-Token

| 参数名 | 类型 | 内容 | 必要性 | 备注 |
| - | - | - | - | - |
| type | str | 类别 | 必要 | `app` |
| page | num | 页数 | 必要 | 从`1`起 |
| firstItem | num | 首个卡片 ID | 非必要 | 一般为第一个页面的第一个卡片 |
| lastItem | num | 末个卡片 ID | 非必要 | 一般为上个页面的最后一个卡片 |
| showAnonymous | num | 显示匿名 | 非必要 | `-1` |

## JSON 回复

根对象：

| 字段 | 类型 | 内容 | 备注 |
| - | - | - | - |
| data | array | 信息本体 | |
